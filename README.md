# DSHsuperagent

Sandbox repository for trialling **dsh-superagent**, the DeepSeek Harness
proactive coding agent prototype
(<https://github.com/deepseek-ai/dsh-superagent-prototype>).

The agent watches this repository for requests. Ask it for work by commenting
on an issue and mentioning its account, for example:

```
@darcysiu fix the typo in src/greet.py
```

Change the repository later in the Superagent panel under **Sources**.
